# Support

Start with the [wiki](https://github.com/JDeffner/px-toolkit-notepadpp/wiki), especially [Installation](https://github.com/JDeffner/px-toolkit-notepadpp/wiki/Installation) and [Troubleshooting](https://github.com/JDeffner/px-toolkit-notepadpp/wiki/Troubleshooting).

Search [existing issues](https://github.com/JDeffner/px-toolkit-notepadpp/issues) before opening a new one. Use the bug form for unexpected behavior and the feature form for a proposed change. Questions, documentation corrections, and maintenance offers can use a blank issue. Report security problems through [SECURITY.md](SECURITY.md).

For a bug, include the plugin and server versions, Notepad++ version and architecture, host OS and version, game, file type, reproduction steps, and expected behavior. For experimental Wine use, also include the Wine version, prefix architecture, and Windows version configured in Wine. A small synthetic mod example is more useful than a complete mod archive. Add a screenshot for visual problems. Remove usernames, personal paths, credentials, and private mod content from logs before sharing them.

This repository handles the Notepad++ plugin. If the same language-server behavior occurs in PX Toolkit for VS Code, the [upstream tracker](https://github.com/JDeffner/paradox-modding-toolkit/issues) may be the better place to report it. If you are unsure, explain what you tested here.

Joel does not use Notepad++ himself. He will look into reported issues, but PX Toolkit for VS Code has priority. There is no guaranteed response time. Anyone interested in taking over maintenance can open an issue to discuss the handover.
